# Domain Glossary

## Actor

A human user who performs an authenticated action through the web or command-line client.

## Human Admin

An active user with an approved Cornell email who can manage annotators, annotation batches, assignments, and releases.

## Annotator

An active user with an approved Cornell email who can view and edit only assigned sessions.

## Account State

The lifecycle state of a human user: pending activation, active, or deactivated. Only active users can authenticate or receive assignments.

## Activation

The single-use, time-limited process through which a pending user chooses an initial password and becomes active.

## Deactivation

The revocation of a user's access. Deactivation must explicitly unassign or reassign unfinished work and does not delete the user or completed work.

## Command-Line Client

A client through which a human user signs in and performs actions using the same identity, role, and permissions as in the web application.

## Session

The unit of annotation presented as raw transcript, manual annotation, and processed reference data.

## Annotation Batch

An immutable selection of versioned raw sessions and processed references imported together for assignment.

## Session Folder

A manually named organizational group of sessions used for navigation, assignment, and progress tracking. A session folder does not identify or imply a provider or source.

## Assignment

The current responsibility for one session held by one annotator. Reassignment changes responsibility without copying the session.

## Annotation Progress

The current assignment state of sessions, summarized across a batch or annotator as unassigned, assigned, in progress, or completed.

## Administrative Action

An assignment, reassignment, reopen, import, export, or account-management mutation attributed to the authenticated human user who performed it.

## Annotation Release

A validated, admin-approved ground-truth publication created from completed annotations. Completed work is not a release until approval and publication succeed.
